# AI 软件公司 CTO 安装包

这是通用的 Codex AI 软件公司 CTO 环境，适用于网站、SaaS、App、2D 游戏和其他软件项目。

## 一键安装

### macOS

1. 点击仓库里的 **install.command** 下载。
2. 双击运行；如果系统拦截，右键选择“打开”。
3. 安装结束后完全退出并重新打开 Codex。

### Windows

双击 **install.bat**，按窗口提示完成安装，然后重新打开 Codex。

### Codex 对话框

也可以把 **START-HERE.txt** 的内容粘贴到 Codex 新任务，让 Codex 自动下载、安装和验证。

## 安装后自检

重新打开 Codex 后，把 **restore-prompt.txt** 的内容粘贴到新任务。自检通过后，以后只需告诉 CTO 产品目标、功能、参考网站或图片和视觉方向。

CTO 会自动读取项目，生成产品地图、页面和状态清单、用户流程、数据流程、验收标准，按需调度设计、开发、测试、独立质检、返工和交付。未验证的内容不会标记为完成。

## 包含内容

- cto-company 通用 CTO 工作流
- 官方 BMAD Method 和 Toolbox
- PM、PO、Architect、UX、Interaction Designer、UI、Frontend/Game、Backend/API、Data、Security、QA、Performance、Release/SRE 等岗位能力
- 产品 intake、页面状态矩阵、交互契约、数据流和质量闸门
- 按需能力包：Python 自动化、BI、数据工程、LLM 应用工程、云计算/DevOps
- 可选 Sleek 移动设计技能

安装包不包含 API key、OAuth、密码、支付凭据或第三方账号。公开安装不需要 GitHub 登录；访问私有仓库或推送代码仍需要相应授权。
