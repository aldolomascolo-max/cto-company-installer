# AI 软件公司 CTO 安装包

在新电脑只安装 Codex 的情况下，下载 cto-company-portable.zip，或把 START-HERE.txt 粘贴给 Codex。

安装包会配置通用的 cto-company CTO 工作流、官方 BMAD 插件、全局规则和项目状态初始化。它包含 PM、PO、Architect、UX、Interaction Designer、UI、Frontend/Game、Backend/API、Data、Security、QA、Performance 和 Release/SRE 角色。

## 使用方式

1. 下载 cto-company-portable.zip。
2. 解压后运行 python3 install.py --project /你的项目目录，或把 START-HERE.txt 粘贴到 Codex 新任务。
3. 按提示完全退出并重新打开 Codex，再粘贴 restore-prompt.txt。
4. 之后只对 CTO 描述产品目标、功能和视觉方向。

安装包不包含 API key、OAuth、密码、支付凭据或第三方账号。当前业务仓库与此安装仓库分离。
